Time Coin (時幣)
A Community‑Driven Time Bank App for Hong Kong’s Ageing Society
HKICT Award 2026 – Tertiary Student Category Entry

📌 Project Overview
Time Coin is a smart, AI‑powered mobile/web application that applies the concept of a time bank to build a self‑sustaining community mutual‑aid ecosystem. It connects neighbours who need help with those who can offer help, particularly targeting the growing number of single‑elderly households in Hong Kong (over 596,000 as of Q1 2025).

Unlike conventional one‑way volunteer platforms, Time Coin enables two‑way interaction: users can both request assistance and offer their skills, earning time coins that can be saved and redeemed for future help. The platform integrates AI‑based intelligent matching, GPS location, and a reputation system to ensure fast, safe, and reliable community support.

🎯 Key Features

Elder‑Friendly UI: High‑contrast colours, large fonts, and intuitive buttons – designed for seniors and users with low digital literacy.

Real‑Name Verification: Identity check (ID card + face photo) to build trust and prevent misuse.

Two‑Way Posting: Users can publish both “I need help” and “I can help” – not just passively wait.

AI Smart Matching: AI recommends the best volunteer based on location, time, skill, and urgency level.

Instant Messaging: In‑app chat with voice input, location sharing, and phone call integration for real‑time coordination.

Time Coin Wallet: Earn coins by helping others; spend coins when you need assistance.

Rating System: After each task, recipients rate volunteers (1–5 stars) to ensure service quality and accountability.

👥 Target Users
Elderly living alone – need help with grocery shopping, medical visits, home repairs, etc.

Students, homemakers, working adults – offer spare time and skills to earn time coins.

Local businesses & NGOs – can join as partners to expand the network and enhance community resilience.

🌍 Social Impact
Reduces social isolation and improves mental health among the elderly.

Empowers seniors to become active contributors (e.g., teaching crafts, sharing life experience) – not just passive recipients.

Relieves pressure on professional care workers and public healthcare resources.

Strengthens neighbourhood solidarity and intergenerational understanding.

Promotes digital inclusion by motivating seniors to use smartphones and digital tools.

🔬 Innovation vs. Existing Platforms

Direction:
Traditional Platforms: One‑way (request only)
Time Coin: Two‑way (request + offer)

Matching:
Traditional Platforms: Manual / basic search
Time Coin: AI + GPS + urgency ranking

Trust:
Traditional Platforms: Low (no verification)
Time Coin: Real‑name + rating system

Sustainability:
Traditional Platforms: Relies on external funding
Time Coin: Self‑sustaining via time coin economy

Coverage:
Traditional Platforms: Limited to specific districts
Time Coin: Whole Hong Kong (scalable to other regions)


Backend: (planned) Node.js / Firebase or Supabase

Mapping: Google Maps / OpenStreetMap API

🚀 How to Run the App (Local Development)
1. Clone the repository

git clone https://github.com/chenzili764-max/Time-Coin.git
cd Time-Coin

2. Install dependencies

npm install

3. Start the development server

npm run dev

4. Open your browser and go to the local URL shown (e.g., http://localhost:5173).
